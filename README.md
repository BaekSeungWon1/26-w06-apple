# 🍎 사과 열매

이웃한 숫자를 드래그로 연결해 사과를 수확하는 8×8 숫자 퍼즐 게임입니다. 60초 동안 합이 10의 배수가 되는 숫자 조합을 찾아 최고 점수에 도전해 보세요.

## 게임 소개

- 게임 시작 버튼을 누르면 1분 타이머와 함께 새 판이 시작됩니다.
- 상하좌우로 이어진 사과 숫자를 드래그해 선택합니다. 합계가 10의 배수라면 선택한 사과가 수확됩니다.
- 수확한 숫자의 합만큼 점수를 얻습니다. 수확한 열에서는 위쪽 사과가 아래로 내려오고, 맨 위 빈자리는 새 사과로 채워집니다.
- 최고 점수는 브라우저에 저장되며, 신기록을 세우면 컨페티 효과가 나타납니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript로 만들었습니다. 포인터 이벤트로 마우스와 터치 드래그를 처리하고, 게임판·점수·타이머 상태는 JavaScript에서 관리합니다. 최고 점수 저장에는 브라우저의 `localStorage`를 사용합니다.

## 실행 방법

별도 패키지 설치 없이 [index.html](./index.html)을 브라우저에서 열어 실행할 수 있습니다. GitHub Pages에 배포할 때도 저장소 루트의 `index.html`을 시작 페이지로 사용합니다.

## 커스터마이징한 부분

기본 규칙을 1분 제한과 10의 배수 합산으로 바꾸고, 숫자 타일을 사과 이모지와 함께 표시합니다. 수확 후에는 열 단위로 사과가 내려오며 새 사과가 보충됩니다. 반응형 레이아웃, 실시간 점수·타이머 표시, 신기록 컨페티 효과도 추가했습니다.

## 파일 구성

- `index.html`: 게임 화면과 접근성 레이블
- `style.css`: 게임판, 애니메이션, 모바일 대응 스타일
- `script.js`: 숫자 선택, 점수, 타이머, 저장 및 효과 처리

자세한 실습 절차는 [guide.md](./guide.md)를 참고하세요.
